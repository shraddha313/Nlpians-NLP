-------------------------Assignment -1 ------------------------

1. Dataset Preparation


3000 documents collected for training and 1000 documents for testing, all from the Computer Science domain.


2. Data Cleaning

Each document is cleaned through the following steps:


Removal of stopwords
Removal of URLs
Removal of bullet points
Handling of apostrophes
Handling of hyphens
Removal of enumerations (e.g., ordered/unordered list markers)
Numerical-to-text conversion (e.g., converting digits into their word form)
Removal of punctuation


3. Case-Insensitive Vocabulary


Word counts are normalized so that variations like "Invalid" and "invalid" are treated as the same token, ensuring a case-insensitive vocabulary/database.


4. Input, Output & TF-IDF Matrix Construction


Input matrix — marks a 1 for the presence of the target word in a given sentence.
Output matrix — marks a 1 for the presence of context words surrounding the target word.
TF-IDF matrix — each sentence is treated as a "document" to compute IDF, accounting for all words within the defined context window.


5. Model Training


A forward pass is computed using the softmax activation function.
Loss function: Negative Log-Likelihood (NLL).
Both the context embedding matrix and target embedding matrix are updated during training via backpropagation.


6. Evaluation


Model performance and word similarity are evaluated using Cosine Similarity between learned word embeddings.
